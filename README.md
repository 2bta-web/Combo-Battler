# コンボローグストライク

OSU風ターゲットをタイミングよく撃ち抜け！コンボを繋いで15種の強化を駆使し、敵を倒すコンボアクション×ローグライトゲーム。

**プレイはこちら** → https://xiaolincangkong5-web.github.io/Combo-Battler/

## 操作

- **Space / Enter / 左クリック**: 攻撃（マウス位置のターゲットを狙う）
- **Esc**: ポーズメニュー
- **スマホ**: タップで攻撃 / ⏸ボタンでポーズ

## ゲームシステム

### 判定

| 判定 | ダメージ倍率 | 条件（アプローチリング進行度） |
|:----|:-----------:|:----------------------------|
| Perfect | ×1.5 | 進行度 67%未満 |
| Good | ×1.0 | 同 39%未満 |
| OK | ×0.6 | 同 11%未満 |
| Early | ダメージ0、ストリークリセット | 進行度が11%を超過 |

※アプローチリングがターゲットと重なるタイミングがPerfectの目安。

### コンボ

コンボ数に応じて与ダメージが増加（ベース倍率 0.8/コンボ）。
コンボ15で**FEVERモード**発動（30秒間スコア2倍、クールダウン60秒）。

### ターゲットカラー

| 色 | 出現条件 | 効果 |
|:--|:---------|:-----|
| 青（通常） | デフォルト | 標準 |
| 紫 | Phase2+（確率50%）| スコア×1.5 |
| 金 | Phase4+（確率25%）| ダメージ×1.5、スコア×2 |
| 赤 | Phase6+（確率10%）| ダメージ×2、スコア×3 |

### Perfectストリーク

Perfectを連続すると特定回数達成時にボーナスダメージが発生する。
100回以降は25回ごとにボーナスが追加され、最大+900%まで成長する。

### モード

| モード | 内容 |
|:-------|:-----|
| Standard | 10フェーズ 標準難易度 |
| Hard | 10フェーズ 超速タイミング（ターゲット出現時間短縮・小型化） |
| Endless | 上限なし スコアアタック（Missで即終了） |

### 強化一覧（15種）

各フェーズクリア時に3つの選択肢から1つを選んで強化を取得。ボス撃破時は5つから2つ選択。

| # | 名称 | 効果 | 取得上限 |
|:-:|:-----|:-----|:--------:|
| 1 | 攻撃力UP | 与ダメージ+25% | 無制限 |
| 2 | クリティカル | 10%の確率で3倍ダメージ（100%超で段階的強化） | 無制限 |
| 3 | コンボ倍率UP | コンボ倍率ベース+0.1 | 1回のみ |
| 4 | ターゲット拡大 | ターゲット半径+15% | 2回まで |
| 5 | 余裕UP | ターゲット出現時間+20% | 2回まで |
| 6 | スコアブースト | 獲得スコア+30% | 無制限 |
| 7 | コンボセーフ | Miss時のコンボ減少を3軽減 | 無制限 |
| 8 | チェイン | 5コンボごとに250ポイント加算 | 1回のみ |
| 9 | ラッキー | 10%の確率でフェーズ×100の追加ダメージ | 1回のみ |
| 10 | フィニッシャー | フェーズクリア時にフェーズ×15のスコア加算 | 無制限 |
| 11 | 連撃 | 15%の確率でダメージ2倍（100%超で段階的強化） | 無制限 |
| 12 | 吸収 | 敵撃破時に+200スコア | 1回のみ |
| 13 | エコー | 20%の確率で100%追加ダメージ | 2回まで |
| 14 | 障壁 | Missを1回無効化（使い切り、重ねると回数増加） | 無制限 |
| 15 | オーラ | 10コンボごとに+1.5ダメージ | 無制限 |

### ボス戦

- **Standard / Hard**: Phase10がボス戦（HP3倍）
- **Endless**: 10フェーズごとにボス出現
- ボス撃破時に5つの選択肢から**2つ**の強化を選べる（同一選択肢は元に戻せる）

## 開発

- **言語**: HTML / CSS / JavaScript（フレームワーク・ライブラリ不使用）
- **効果音**: Web Audio API による波形生成（音声ファイル不要）
- **保存**: ハイスコア・設定・レイアウトはlocalStorageに保存
- **動作環境**: デスクトップPC推奨（1920×1080想定）
